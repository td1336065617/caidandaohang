# 菜单导航

一个 AstrBot 聚合菜单插件：发送 `菜单`（或 `菜单导航`），自动汇总已选择插件
的菜单指令，并生成图片发送。

## 文档

- [更新日志](CHANGELOG.md)
- [配置文档](docs/CONFIG.md)

## 插件如何接入

在插件根目录放一个 `menu.md`，内容就是该插件在导航里展示的菜单文本：

```markdown
表情包管理菜单
添加{关键词} - 回复图片批量入库
来只{关键词} - 随机发送一张图片
```

或者在该插件 `metadata.yaml` 里声明：

```yaml
menu: |
  表情包管理菜单
  添加{关键词} - 回复图片批量入库
```

没有提供菜单指令的插件会显示名称与简短描述。

## 行为说明

- `菜单` 为全匹配指令，只有发送完整“菜单”两个字才会触发，不影响聊天内容；
  同时兼容 QQ 官方指令面板添加的 `/菜单`。
- 聚合时只提取各插件的“指令 ─ 简述”条目，不再原样拼接完整 `menu.md`。
- 默认整合全部插件；可在 AstrBot 后台“菜单导航”页面切换为自选插件，
  只聚合勾选的插件菜单。
- 只有收到 `菜单` 后才检查插件菜单是否变化；没有变化时直接复用现有图片，
  新增插件或菜单内容变化时才重新生成 HTML 并转图。
- 转图不依赖 Google Chrome：会自动尝试 Chromium/Chrome、Firefox、
  `wkhtmltoimage`，都不可用时使用 Pillow 绘制 PNG；若 Pillow 也不可用，
  最后退回纯文本分片发送。也可通过 `MENU_NAVIGATION_RENDERER` 指定渲染器路径，
  或指定为 `pillow`。
- 群聊无需 @机器人，私聊也可使用。

## 部署

将本目录放入 `AstrBot/data/plugins/menu_navigation/`，重启 AstrBot 后启用。

启用后在 AstrBot 管理面板 → 插件管理 → 菜单导航中配置菜单整合范围。
