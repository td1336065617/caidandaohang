# 菜单导航

一个 AstrBot 聚合菜单插件：发送 `菜单`（或 `菜单导航`），自动汇总所有
已安装插件的菜单并分条展示。

## 文档

- [更新日志](CHANGELOG.md)
- [配置文档](docs/CONFIG.md)

## 插件如何接入

在插件根目录放一个 `menu.md`，内容就是该插件在导航里展示的菜单文本：

```markdown
表情包管理菜单
添加{关键词} - 回复图片批量入库
来只{关键词} - 随机发送一张图片
```

或者在该插件 `metadata.yaml` 里声明：

```yaml
menu: |
  表情包管理菜单
  添加{关键词} - 回复图片批量入库
```

没有提供菜单的插件会显示名称与描述（并提示未提供 menu.md）。

## 行为说明

- `菜单` 为全匹配指令，只有发送完整“菜单”两个字才会触发，不影响聊天内容。
- 聚合结果超过 1500 字会自动分多条发送。
- 结果缓存 60 秒，插件更新菜单后稍等片刻即可看到最新内容。
- 群聊无需 @机器人，私聊也可使用。

## 部署

将本目录放入 `AstrBot/data/plugins/menu_navigation/`，重启 AstrBot 后启用。
